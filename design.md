# Дизайн Verde Marea

Предварительное визуальное направление проекта. Полная спецификация дизайна будет подготовлена на этапе 1.

## Mediterranean Editorial Minimalism

| Цвет | HEX |
| --- | --- |
| Forest | `#1F4D3A` |
| Brass | `#C7A76C` |
| Ivory | `#F5F1E8` |
| Ink | `#1B1B1B` |

- Cormorant Garamond для заголовков.
- Manrope для интерфейса.

## Принципы

- Элегантная ресторанная эстетика и тёплые светлые поверхности.
- Минимум декоративных эффектов.
- Компактная функциональная административная панель.
- Единая дизайн-система для всех экранов.
- Адаптивность и доступность.

## Исключения

- Сине-фиолетовые градиенты и глассморфизм.
- Случайные акцентные цвета и избыточные тени.
- Типовые SaaS-карточки без функциональной необходимости.
- Декоративные анимации.
